# weixingame
元昱航科技团队协作仓库

本仓库保存2D俯视角开拓守城小游戏的策划、单位资料及Cocos Creator 3.8.8游戏工程。已实现前4回合程序原型与首批建筑图片，角色、地形和多数界面仍为可替换的程序占位表现。

本地试玩、构建和已实现范围见[首战试玩说明](游戏工程/试玩说明.md)。本机完成构建后，可双击根目录的“启动试玩.cmd”，再打开终端显示的本机网址。

- [开发基线](协作开发/开发基线.md)：当前可直接实现的规则和首个可玩版本。
- [首轮任务](协作开发/首轮任务.md)及[GitHub任务列表](https://github.com/zky0124/weixingame/issues)：执行者认领，先做工程、美术基准和前4回合闭环。

本机正式工作目录已统一为 `G:\新游戏项目`，不再在首次上传的旧副本继续修改。协作者在各自电脑克隆同一仓库、使用相同引擎版本。

## 当前范围与状态

- 试玩版覆盖临时庇护所、简易房屋、小型营地、定居点。用户要求有效游玩五小时以内，不含挂机；具体回合、数值和节奏仍属待试玩验证的工作初稿。
- 当前单位资料包含3种士兵、2名低级英雄、8种哥布林部族敌人。单位卡优先于旧策划摘要，保留用户最新改名、属性与技能。
- 已保存用户给出的弓箭手、战士、魔法师、辅助、盾卫、刺客、护卫、攻城、武道家九职业；文档会区分用户核心要求和助手补齐的执行细节。
- 微信、抖音、TapTap为目标平台；开发者资质、商业化接入和正式审核尚未完成。
- “已确认”按用户明确要求理解；带“初稿、建议、待调试、历史问题”的内容用于继续设计，不代表全部已经定案。

## 单位资料的维护

编辑对应单位文件夹中的 `属性设定.md`。不要直接修改生成的速查表或网页作为唯一数据源。

安装Node.js 24或兼容版本后，在仓库根目录运行：

```sh
node 工具/刷新单位图鉴.cjs
node 工具/检查项目资料.cjs
```

Windows也可双击 `游戏策划/单位资料/刷新图鉴.cmd`。它会从当前单位卡更新分类速查、梗概与离线图鉴，不修改单位卡。

`游戏策划/单位资料/单位图鉴.html` 是单文件离线图鉴，克隆/下载仓库后用浏览器打开即可搜索、按职业筛选和进入详情。GitHub文件页面显示HTML源码，当前未部署GitHub Pages。

## 文件边界

仓库同步策划、属性文本、离线图鉴、游戏源码和维护脚本。开发工具安装包、软件目录、构建输出、缓存、临时文件、账号凭据和本地备份不上传。

开发环境讨论文档中的G盘位置是原电脑的本地安装记录，可供参考；仓库阅读链接与图鉴刷新脚本使用相对位置，其他电脑无需拥有相同G盘目录。
