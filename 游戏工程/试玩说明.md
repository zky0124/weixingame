# 首战程序原型 v0.1.3

这是用于确认战斗、经济与手机操作的可玩原型。名称“蛮荒开拓”为临时界面标题；已接入庇护所、简易房屋和农田的首批原创建筑图片。角色、地形和大部分界面仍为程序占位表现，完整动画与音效尚未制作。

## 怎么试玩

本机已经构建后，在仓库根目录运行 `工具/启动首战试玩.ps1`，保持终端开启，再打开[本机试玩入口](http://127.0.0.1:7456/preview)。入口只对本电脑开放，不能发给好友直接访问。也可双击[启动试玩](../启动试玩.cmd)。

克隆仓库的协作者需先使用Cocos Creator 3.8.8打开本文件夹，等待导入资源，再执行一次web-mobile构建。构建输出不上传GitHub。

```powershell
# 本机默认引擎路径已配置；其他电脑通过参数传入实际引擎路径。
& ./工具/构建首战.ps1 -Creator路径 'G:\游戏开发环境\引擎\CocosCreator.exe'
& ./工具/启动首战试玩.ps1
```

运行脚本从当前仓库定位游戏工程，不依赖协作者拥有相同项目目录。构建方式参照[Cocos官方命令行构建说明](https://docs.cocos.com/creator/3.8/manual/zh/editor/publish/publish-in-command-line.html)。

## 可以体验什么

1. 点击开始首战：3名护卫自动迎击3只哥布林散兵。主城不射箭。
2. 每只哥布林掉1铜币，首胜国王另送50铜币，合计53铜币。
3. 点击战场中央主城（或“进入主城”），进入独立经营地图。花30铜币升级简易房屋，在底部选择农田，点按地图预览2×2占地，选好合法位置后确认花5铜币建造，剩18铜币。
4. 农田在线每10秒产1铜币；之后每次迎敌另得1铜币，两者叠加。建设界面打开时外部战斗照常继续。
5. 可花1铜币招募护卫，双击哥布林下达全军集火。前4回合完成后显示原型完成，不进入无限循环。
6. 清场后画面持续运行，存活护卫步行回到各自的驻守位置，随后循环播放占位待机动作；不免费回血或复活。农田只显示在城内地图，回到战场仍继续产出。
7. 城内地图可拖动浏览，顶部可取消选址或归中。红色预览表示主城/通路重叠或越界，不能建造；取消不花钱。点击已建建筑查看信息，真实位置随存档恢复。
8. 建筑图片异步加载后显示；加载失败时保留占位显示并提示。升级会切换庇护所/房屋外观，农田图片只出现在城内。素材说明见[第一批建筑](../美术资源/建筑/第一批/素材说明.md)。

程序支持鼠标和引擎触摸事件。测试页可在电脑、小手机、宽屏手机、平板及竖屏提示间切换；不重建战斗。竖屏提示暂停战斗与刷怪，农田仍按前台运行时间计时。

## 存档与失败

- 每约0.5秒及操作后自动写入当前设备/浏览器本地存档。交战中刷新会恢复双方位置、血量、冷却、回合和钱款，不重新发奖。
- 切后台或关闭后暂停模拟，不补离线收益。当前没有云备份和跨平台同步；清理浏览器数据会丢失进度。
- 城池耐久为0判负。免费回到战前会回滚整次尝试，包括掉落、建设、招募和本回合农田所得；不是免费复活死去的单个单位。
- 设置内有明确的“确认清空并重开”按钮，供重新试玩教学。
- v0.1.0旧存档继续有效，加载时为护卫补齐驻守编号；已有农田移到城内显示，不重复扣费。
- v0.1.1等旧存档中缺少农田坐标时，补到默认合法网格位置，已有钱款、收入和战斗进度保留。

## 此原型的执行初值

| 项目 | 当前初值 | 说明 |
| --- | --- | --- |
| 城池耐久 | 100 | 用于首轮玩法测试，暂不提供城池回血 |
| 部队上限 | 8名护卫 | 初值，存活护卫不会在回合间自动回满血 |
| 前4回合组成 | 3、4、5、6只散兵 | 验证连续流程，不代表正式关卡配置 |
| 伤害下限 | 0 | 攻击减护甲，允许负护甲增伤；本版只有物理普通攻击 |
| 逻辑更新 | 固定30步/秒 | 帧率与攻速分离；前台严重卡顿不补跑大段战斗 |
| 镜头 | 固定16:9核心视口 | 等比缩放并留边，保持人物和城市比例 |

护卫与散兵的血量、攻击、护甲、攻速、射程和速度由当前单位卡生成，修改属性卡后运行 `node 工具/同步首战单位.cjs`。不要直接改单独生成的UnitData.ts。

## 验证与暂未实现

仓库根目录运行：

```sh
npm ci --prefix 游戏工程
npm test --prefix 游戏工程
# 先由Creator导入生成temp类型声明后，才能执行完整引擎脚本类型检查。
npm run typecheck --prefix 游戏工程
node 工具/检查项目资料.cjs
```

自动验证覆盖经济结算、防重复奖励、农田叠加、4回合、集火、失败回滚、存档一致性及无效数据，以及战后回位、补员槽位、网格投影、建筑占地、非法位置不扣费、建筑位置保存恢复和旧版迁移；另检查建筑PNG的真实透明通道、哈希、可见范围与SpriteFrame裁边。不替代浏览器画面与实机验证。
