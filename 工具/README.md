# 策划维护工具

运行环境：Node.js 24或兼容版本。当前刷新脚本只使用Node内置模块，不需要npm安装依赖。

从仓库根目录执行：

```sh
node 工具/刷新单位图鉴.cjs
```

脚本自动定位仓库内的单位资料，从各单位“属性设定.md”读取当前名字、职业、属性、技能和行动规则，更新分类概览、单位总目录、哥布林部族梗概与离线HTML。

运行时生成的索引存入 `.本地缓存`，已经排除Git跟踪。Markdown链接按输出文件的位置生成相对路径；网页单位详情内显示仓库相对文件位置。

修改单位卡后重新运行脚本并提交生成文件，其他人即可看到一致的速查信息。职业规则编辑源为 `游戏策划/单位资料/职业设定/职业规则.md`。
