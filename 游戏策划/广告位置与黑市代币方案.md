# 广告位置与黑市代币方案

日期：2026年10月28日；状态：用户新增方向与助手建议分别标注。具体奖励价格、频率、英雄身份和各平台可用性尚未定案。

## 用户已明确的方向

- 所有广告由玩家自愿点击。
- 增加看广告获得英雄帅气皮肤的途径。
- 前期可通过看广告获得某位指定英雄。
- 领取奖励时，可以选择看广告增加额外奖励。
- 看广告后同时获得广告代币，在黑市商人处购买东西。
- 试玩版止于阶段1“定居点”；新增广告方向不表示所有广告位都必须进入试玩版。

## 广告位置总表

| 位置 | 奖励与体验 | 当前状态 |
| --- | --- | --- |
| 战败界面 | 紧急救援，继续本场战斗 | 前轮候选；恢复量、免费重试与永久死亡边界待定 |
| 离线收益界面 | 免费基础收入之外的一份额外收入 | 前轮候选；离线系统和倍率待定 |
| 战斗或阶段奖励结算 | 正常奖励之外的额外奖励 | 用户新增确认方向；不代表每次掉落都弹出广告 |
| 前期开拓援军/指定英雄展示 | 获得一位明确展示的英雄 | 用户新增确认方向；英雄品质、解锁时点、次数及其他获取途径待定 |
| 英雄皮肤展示或衣橱 | 获得所选皮肤 | 用户新增确认方向；直接解锁或代币兑换、价格待定 |
| 黑市商人 | 使用广告代币兑换商品 | 用户新增确认方向；它是消费入口，不自动成为新增广告播放入口 |

## 广告代币建议（待确认）

用户所说“只要看广告就有代币”，建议定义为：每次由玩家主动选择并获得平台有效完成确认的激励广告，发放原场景奖励及固定广告代币。点击按钮、仅打开广告、提前退出、加载失败不等同于有效完成。平台对失败兜底有特殊要求时单独适配，不以虚假完成记录模拟真实观看。

- 可先讨论每次有效完成给予1枚代币，数量尚未定案。
- 同一次有效观看只发一次代币；切后台、重复回调、重启游戏不能重复领取。
- 在广告按钮或奖励说明中预先展示“本次奖励＋代币”，观看完成立即兑现，不要求再看一次广告才能领取。
- 代币建议不可充值、提现、交易或转赠，不提供现金含义。
- 黑市建议明码标价、固定商品，先不做抽奖、转盘或赌博式玩法。
- 商店可售纯外观皮肤、小额资源、普通补给；商品范围是建议，尚未确认。
- 不要求连看多条才拿到第一次奖励；各平台对累计广告换稀有奖励的具体边界仍需验证。
- 不以每天强制完成的观看任务催促玩家，未使用代币建议不设置短期过期。

## 英雄与皮肤的设计衔接

建议皮肤只改变外观和特效，不提高战斗属性；不把通关必需能力锁在广告后。

指定英雄建议采用一次性、可预览、非随机的获取方式；是否同时提供正常游戏获取途径，需用户确认。若该英雄属于低级英雄，仍受永久死亡规则约束，不能未经确认改成无限广告复活；更适合讨论广告解锁招募资格，或获得一次单位后允许普通资源重招。

皮肤建议属于永久收藏，不因对应低级英雄死亡而消失，并可应用到后来重新招募的同名英雄；此项为建议。

## 控制总量

新增广告位不自动增加整段体验的广告密度。奖励结算仅在有意义的关卡或阶段出现可选加成，不对每只野怪或每次收菜弹窗。所有位置共享频率统计，不能各自冷却却叠加刷屏。

试玩版建议从指定英雄一次性奖励、重要结算加成中挑选少量入口，再视失败恢复方案加入救援。皮肤与黑市可先保留少量展示商品；具体首发清单还未确认。此前“首版先做救援和离线”仅为旧建议，不再视为固定优先级。

所有规则需做到不看广告也能正常完成试玩版；使用测试广告或模拟完成流程调试，不以开发者反复观看正式广告来测试。

## 关联待确认项

- 哪位指定英雄、品质与死亡后的处理？
- 皮肤直接看广告解锁，还是消耗广告代币，或两种方式并存？
- 代币数量、黑市价格及同场景奖励与代币叠加后的经济影响？
- 玩家不看广告时获取该英雄、皮肤的渠道？
- 哪些入口进入试玩版，哪些留到正式版？
