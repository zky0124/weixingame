# 科技树系统

全部科技树资料保存在本文件夹。入口：[科技树系统](科技树系统.html)，正式填写稿：[科技树系统.json](科技树系统.json)，效果执行对照：[科技执行映射.json](科技执行映射.json)。已收到18项科技，原节点名称、位置和填写内容保留。

推荐从项目根目录运行 `node 工具/科技树预览服务.cjs`，打开 http://127.0.0.1:7466 。点“保存到项目”写入本目录的科技树系统.json；之后合法编辑会自动保存。原项目版本自动备份到不提交Git的本地缓存，遇到文件版本冲突先保留两份，不静默覆盖。点“载入项目”读取文件，覆盖本机草稿前会确认。

双击HTML也能使用，但只能保存浏览器草稿或手动“保存为 JSON”；浏览器数据不等于项目文件。GitHub文件页显示源码，需克隆后使用。导出也可通过“备份文本”另存UTF-8 JSON。

- 点击科技点，右侧填写名称、最高等级、每级研究点/铜币、效果和条件。
- 新建分支从研究塔出发，“下一级”从选中科技继续延伸。新增后自动全览，节点可自由拖动。
- 点“连线”，依次点前置科技和目标科技，即可跨路线合流。默认全部满足；右侧可选任一满足。上游主路径也参与条件判断，右侧“解除”删除额外连线。禁止自身依赖、重复连线和循环。
- 多级科技用同一节点的最高等级表示；等级不是玩家当前研究进度。前置默认要求对应科技满级，每级费用按填写数值重复支付。
- 空白费用表示尚未确定，0才是免费。目前T006弓手路线“熟练老手”的研究点留空，执行层暂不允许购买。
- 整理布局不改效果；删除、导入可撤销。被其他节点依赖的科技需先解除依赖再删除。

[研究塔与科技生效规则](研究塔与科技生效规则.md)记录执行细节和当前程序边界。运行 `node 工具/同步科技设定.cjs` 从填写稿生成运行配置；效果文字变化须先核对执行映射，脚本不会任意执行文本，也不会用初始模板覆盖原稿。原[Excel](研究塔科技树填写表.xlsx)保留作历史参考，不双向同步。
