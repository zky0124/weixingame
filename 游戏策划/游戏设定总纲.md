# 游戏设定总纲

版本：v0.4
整理日期：2026年10月28日
状态：根据用户首轮设定整理；剧情补写已单独标记，未确定的执行规则见《待确认事项与设计衔接》。

## 一、定位与核心体验

- 类型：2D俯视角城堡防守、城市建设、科技成长，后期加入军团与远征。
- 目标平台：微信小游戏或抖音小游戏，也考虑TapTap，最终选择待定。
- 内容结构：可以通关、有完整结局的单机式体验，不以无限运营、无限等级或同种敌人反复换皮涨数值为目标。
- 收入方向：广告变现，具体广告位与奖励规则待定。
- 操作对象：主城、建设与成长系统、回合推进；没有玩家直接操控移动的主角。
- 战场结构：主城位于中央，敌人从地图外围进攻，我方部队在主城外围自动作战。
- 成长体验：从几个护卫保护简陋居所，逐渐发展为城市、军团与帝国。

核心循环：抵御入侵并获得奖励 → 建设产业与升级主城 → 解锁科技、兵种和新系统 → 提升实力 → 主动推进回合并迎接更强敌人。

玩家发展受阻时，可以暂缓推进回合，依靠已有建设获得收入，逐渐积累实力后再继续战斗。

## 二、美术方向

以《王国保卫战》的2D手绘卡通观感为主要参考，建立自己的角色、建筑和视觉特色。

- 视角为俯视并带一定倾斜角度，建筑具有顶部与正面的立体表现。
- 美术方向包括清晰轮廓、深色描边、夸张比例、中世纪奇幻题材与容易辨识的战场单位。
- 具体角色、建筑、界面、插画与动画制作原创资产，不直接搬用参考游戏成品素材。
- 每个主城成长阶段需要区别化的外观、立绘和动画表现；具体资源拆分后续确定。
- 英雄在统一画面风格下，允许同时存在帅气正统与抽象玩梗两类表现。

## 三、世界观与剧情

### 已确认的故事主线

玩家是王国派往蛮荒平原的开拓者，获得国王提供的一些初始资助。从简陋居所起步，抵御哥布林等敌人的袭击。

第三大阶段，原来的国王被叛军击败，旧首都毁于火海。玩家开拓出的城市成为新王国首都，继续向帝国发展。

### 开场剧情草案（助手补写，可修改）

王国边境之外，蛮荒平原曾是商旅不敢踏足的荒地。如今边境资源日渐紧缺，国王决定招募开拓者，在平原上建立新的定居点。

你领到一纸开拓敕令、一些搭建住所的物资，以及三名奉命护送你的护卫。王国承诺：每消灭一名威胁新领地的哥布林，便支付一枚铜币作为赏金。

没有高墙，没有军队，甚至没有像样的屋顶。你的领地，最初只是一块被粗陋围栏圈起的土地。

多年之后，一封急报从王都送来：叛军攻破了首都，王宫陷入火海，国王败亡。昔日的边疆据点，成为重建王国的希望。你将从开拓者转变为新秩序的建立者。

说明：敕令、建造物资、急报与文案措辞属于补写；初始资助的具体资源数量未确定，不据此增加开局货币。

| 阶段1：生存阶段 | 3 | 小型营地 |
| 阶段1：生存阶段 | 4 | 定居点 |
| 阶段2：城市聚落阶段 | 5 | 小型村落 |

注：阶段3的大阶段标题是整理用概括，尚未正式命名；其四个成长节点为用户指定。

### 阶段1：生存阶段

- 起点是简陋居所和粗略圈起的土地，没有成熟城市系统。
- 初始居所无法射箭，也没有其他已解锁的生产或研究能力。
- 初始提供3名护卫，由护卫抵抗首次入侵。
- 主城第一次升级后解锁种田与第一块土地。
- 城堡形成前，可以向国王付费招募基础护卫。

### 阶段2：城市聚落阶段

- 进入具备城堡、城墙与城市产业的发展时期。
- 城墙保护城堡，城内可建设产业并升级设施。
- 可以建造弓箭塔，向外射箭，支援城外部队。
- 城堡、城墙、弓箭塔分别在哪个成长节点解锁，尚未确定。

### 阶段3：巨城与国家发展阶段

- 发生旧王国覆灭、旧首都被毁的剧情转折，并走向新首都与帝国建设。
- 我方主要作战形式转变为军团，敌人也以军团和集群方式进攻。
- 不再仅由几个独立小兵在城外交战；战斗单位以多名士兵组成的集团形式表现。
- 剧情触发节点、军团正式开放节点与“王国首都”成长节点的衔接，后续细化。

## 五、开局与教学流程

| 步骤 | 事件 | 玩家学习内容或结果 |
| --- | --- | --- |
| 1 | 玩家抵达蛮荒平原，拥有简陋居所与3名护卫 | 了解开拓者身份与守卫主城的目标 |
| 2 | 哥布林首次入侵，教学描述中共3名 | 居所不能射箭，护卫自动上前作战 |
| 3 | 护卫击杀哥布林 | 国王按每只1铜币发放奖励，3只共3铜币 |
| 4 | 第一波结束，国王送来50铜币，教学提示升级主城 | 花费30铜币完成第一次主城升级 |
| 5 | 解锁种田，点击主城进入内部界面 | 获得第一块可建设土地 |
| 6 | 在土地上修建农田 | 建造需要5铜币，启动持续收入 |
| 7 | 退出主城界面，返回战斗地图 | 认识战斗地图与主城内部界面的切换 |
| 8 | 收到新的敌人进攻消息，显示迎敌入口，无倒计时 | 学习主动迎敌、回合前进与奖励 |
| 9 | 玩家推进回合，迎接下一批哥布林 | 敌人仍较弱，玩家能轻松应对，基础教学接近结束 |

教学初期的敌人用于提供低压力的胜利体验、成长反馈和货币来源。用户提到敌人“送经验送钱”，但经验的归属与用途尚未定义。

教学资金已衔接：不计其他初始货币、额外支出和时间收入，3铜币击杀奖励＋50铜币国王资助－30铜币主城升级－5铜币农田建造＝剩余18铜币。正式初始货币仍需测试确定。

## 六、经济与回合前进

### 当前明确的初始数值

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 初始护卫 | 3名 | 开局提供 |
| 基础护卫招募 | 1铜币/名 | 城堡阶段之前向国王招募 |
| 首次哥布林赏金 | 1铜币/只 | 由国王奖励 |
| 首次入侵击杀奖励合计 | 3铜币 | 教学描述为击杀3只哥布林 |
| 第一波结束国王资助 | 50铜币 | 额外送达 |
| 首次主城升级 | 30铜币 | 教学升级费用 |
| 第一座农田建造 | 5铜币 | 首次升级主城后解锁 |
| 农田时间收入 | 每10秒增加1铜币 | 初始数值 |
| 农田回合收入 | 每前进1回合增加1铜币 | 与时间收入叠加，迎敌推进时获得 |

经济数值通过测试持续调整：前期升级简单，后期花销指数级增长，具体曲线未定。农田被动收入与回合主动收入叠加；只要游戏在运行就产生时间收入，包括战斗与主城界面。离线收益后续讨论，平台切后台后的挂起情况需要另行定义。

货币兑换：100铜币＝1银币，100银币＝1金币，100金币＝1铂金币。解锁银行后自动换算持有金额与支付找零：500铜币显示为5银币，购买20铜币物品后显示4银币80铜币。银行解锁前后的总财富价值保持一致；银行不产生兑换收益。解锁前高额财富的显示规则待细化。

### 回合前进

- 无倒计时。玩家迎敌即推进一个回合并获得奖励，回合负责主线剧情推进。
- 玩家可以暂不推进主线回合，依靠建设发展；这不代表战场绝对安全，因为存在自动进攻的野怪。
- 野怪自动刷新并进攻城镇，其等级、强度与刷新频率另设系统，不直接等同于主线回合敌人。
- 主线回合启动后停止刷新新的野怪，直到该回合战斗结束（怪物全死或城池被攻破）。
- 已在与玩家交战的野怪不消失，继续战斗。尚未接战的存量野怪如何处理，以及“怪物全死”的计数范围，待细化。
- 回合奖励具体额度、失败重试能否再次领取以及清场前能否开启下一回合，后续确定，避免重复领取漏洞。

## 七、战斗地图、主城内部与比例规则

游戏包含战斗地图与点击主城进入的主城内部界面。

### 战斗地图

- 展示中央主城、城外友军、进攻敌人及地图边缘的回合入口。
- 随发展推进，可见视野越来越大。
- 主城成长时外观变化，但不因城市实际面积增长而在战斗地图中无限扩大占地。
- 人物与城市的既定视觉比例保持一致，不通过把城市不断放大或把士兵不断缩小来表现成长。
- 第三阶段的变化是将单兵的战斗表现转向多名士兵聚集组成的军团，而非将单个人物放大。

### 主城内部

- 点击主城进入，退出后回到战场。
- 进入主城内部时，外部战斗仍继续。
- 展示土地、产业、建筑及升级内容。
- 城市规模扩张主要在主城内部体现，战斗地图保持稳定的主城表现尺度。

“视野扩大”如何通过镜头、地图边界或可见区域实现，后续确定，并以保持上述比例规则为约束。

## 八、兵种、研究塔与科技树

- 初期护卫是最基础、战斗能力较弱的兵种。
- 解锁研究塔后开放科技树。
- 研究点用于兵种成长，具体获取方式未定。
- 每一个兵种都可以通过科技继续升级，初始低级兵种不应在后期失去成长价值。
- 只要拥有足够研究点，最基础的护卫也能逐步成长为顶级兵种。
- 升级路径、分支、转职和上限未定，不预设统一的升级或淘汰规则。

### 统一单位属性框架

兵种与怪物采用逻辑一致、可比较的属性体系。

| 属性 | 当前定义或要求 |
| --- | --- |
| 攻击力 | 物理伤害基础值减护甲；魔法伤害基础值减魔抗 |
| 血量 | 单位生存能力 |
| 护甲 | 对物理伤害做减法，允许负值；魔法伤害无视护甲 |
| 攻击速度 | 每秒攻击次数 |
| 近战/远程 | 作战类别 |
| 攻击方式 | 物理或魔法；具体弹道及范围表现另行设计 |
| 魔法抗性 | 对魔法伤害做减法，允许负值 |
| 攻击距离 | 近战默认1；距离1对应的实际尺度待定 |
| 特殊技能 | 单位的特殊战斗能力 |
| 职业 | 单位定位与职业分类，职业列表待定 |

伤害示例：10物理攻击－1护甲＝9伤害；10魔法伤害－1魔抗＝9伤害。负抗性增加对应伤害，例如10－（－2）＝12。防御高于攻击时伤害最低为0还是1、取整及护盾等规则尚未确定，不能自行认定负伤害会治疗目标。

### 战斗执行与指挥

最新职业规则取代下方旧通用寻敌摘要：弓箭手、战士、魔法师、辅助、盾卫、刺客、护卫、攻城、武道家按各自优先级行动；完整定义见[职业规则](单位资料/职业设定/职业规则.md)。当前单位名、基础属性与个体技能以[单位资料](单位资料/单位资料说明.md)中的当前卡片为准。民兵与哥布林战车采用新名称；敌人归入哥布林部族，狼仍为野兽；原草药医护不在当前名单。

- 攻击距离的实际尺度、寻敌、主城耐久等需要开发时反复测试调整；近战距离默认值仍为1。
- 技能分主动和被动，技能自动释放；需要冷却的技能按CD执行，不空放，优先选择场上最有价值的目标。持续被动与触发被动的具体冷却规则逐项设计。
- 护卫属于普通士兵，可直接招募；其他兵种在对应兵营花钱招募补员。普通士兵死亡后的详细损失规则尚待明确。
- 敌人直接攻击或技能命中城池都会造成城池掉血，城池血量清零即失败。恢复规则后续讨论。
- 双击某个敌人，将其设为所有我方单位优先处理的主要目标。
- 点击英雄头像，再点击敌人，可单独指挥该英雄攻击指定目标；与全军指令的优先级、失去目标后的处理待细化。
- 玩家进入主城界面时战斗继续；技能的“主动”分类不表示玩家必须手动释放。

## 九、军团与远征

### 军团系统

- 前期以单兵作战为主。
- 城堡和城市发展后，敌人会发动集群突袭。
- 我方随发展和升级解锁军团作战。
- 后期我方与敌方均以军团为主要战斗形式。
- 参考《小小军团》的军团作战体验与成组士兵表现；具体编队、人数、指挥、寻路与伤亡规则尚未确定。
- 军团方向保留，具体设计暂缓。

### 远征系统

- 后续解锁，具体主城等级或条件待定。
- 对战方式参考《小小军团》。
- 暂定作为稀有高级英雄的概率获取渠道，后续补充其他获取方式。
- 远征目标、地图、消耗、收益、失败代价和是否可重复尚未确定。

## 十、英雄系统

### 风格分类

英雄存在两种创作方向：正常帅气的英雄，以及带抽象、玩梗气质的英雄。用户举例“奶蛙”作为抽象感参考，尚未确认具体角色及其形象。

风格分类与品质分类是两套概念，不把“帅气/抽象”绑定为“高级/低级”，也不擅自设定阵营对立。

### 品质与获取

| 类别 | 视觉标识 | 初步获取方式 | 战斗定位 |
| --- | --- | --- | --- |
| 低级英雄 | 红色标识，具体红色应用位置待细化 | 一般在酒馆招募 | 相当于主要基础属性大幅加强的小兵 |
| 高级英雄/稀有英雄 | 金色框并带特效 | 暂定通过远征概率获取，后续丰富渠道 | 较强且具有差异化技能的稀有单位 |

保留用户指定的“红色低级、金色高级”规则，不按其他游戏的常见品质排序调整。“三维属性”是各项属性的泛称，并非限定为三个属性。

### 技能与死亡

- 英雄整体比普通单位更强，但仍然会死亡。
- 英雄可以拥有额外主动或被动技能。
- 高级英雄通常具有2个特殊技能，每名英雄效果不同，后续逐一设计。
- 低级英雄有技能，一般为被动技能；死亡后永久消失，不允许复活，但可重新招募。
- 后期城市可建设神殿，用于复活自己的高级英雄。
- 高级英雄的复活成本、等待时间、死亡后保留内容与具体设计后续讨论。
- 英雄技能同样自动释放，不空放并优先选择高价值目标。

## 十一、成就与彩蛋

- 建立随玩家发展阶段逐渐解锁的成就系统。
- 在战斗地图或城市内部放置彩蛋。
- 完成成就或发现彩蛋可以给予玩家奖励。
- 成就清单、彩蛋表现、触发条件、奖励种类与重复领取规则后续设计。

## 十二、当前边界
