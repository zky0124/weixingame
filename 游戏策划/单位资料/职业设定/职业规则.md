# 职业规则

更新日期：2026年11月4日。九种职业的核心描述来自用户，敌我共用。种族、所属势力、职业、品质、护甲类别和伤害类型是不同字段。

## 九种职业

| 职业 | 类型 | 默认行动与目标优先级 | 职业能力 |
| --- | --- | --- | --- |
| 弓箭手 | 远程攻击 | 优先攻击射程内的第一个单位 | 不限定武器必须是弓，投石等普通远程也归此类 |
| 战士 | 近战 | 优先攻击离自己最近的敌人 | 具体技能由单位定义 |
| 魔法师 | 远程攻击 | 射程内重甲单位优先，其次射程内其他单位 | 普攻伤害类型依单位卡，本批巫徒为魔法 |
| 辅助 | 医疗或其他支援 | 与本方远程攻击单位同行；治疗优先近战友军 | 不空放、不治疗满血；非治疗辅助按其技能工作 |
| 盾卫 | 重甲近战 | 优先攻击最近敌人 | 重甲标签，不自动提高数值护甲 |
| 刺客 | 近战或单位指定方式 | 辅助 → 远程攻击单位 → 护甲最低的近战 → 最近敌人 | 优先级在有效索敌范围内执行 |
| 护卫 | 重甲近战 | 主动迎敌；后排受攻击时，立即优先追击攻击者 | 为受保护远程分摊30%伤害；对刺客额外30%伤害 |
| 攻城 | 重甲远程 | 优先攻击城堡 | 对城堡额外50%伤害，一般为敌方单位 |
| 武道家 | 特殊，近战/远程皆可 | 单位专属的技术和游走行为 | 具体技术后续逐个设计，不凭空给现有单位加此职业 |

## 执行口径（助手补齐初稿，可调整）

### 第一单位、重甲与命令

- 弓箭手的“第一个”解释为最先进入其有效射程的敌人，目标有效时持续攻击；同时进入以距离、稳定单位序号排序，避免每帧乱换目标。
- 魔法师在重新选目标时先筛重甲；同级按进入射程顺序。若新的重甲进入，下一次发起攻击前优先重甲，不取消已经发射的法弹。
- 重甲是明确标签，由单位卡记录；不设“护甲超过某值自动重甲”，否则当前用户填写的数值与职业容易冲突。魔抗为负也不改变职业。
- 玩家指定英雄命令优先于全军集火，之后才是职业默认目标；受射程、活动区域和技能合法性约束。辅助不因攻击命令变成伤害单位，护卫保护被动不会被命令取消。
- 刺客同一优先级按距离；最低护甲比较当前战斗护甲，含负值和光环。活动范围内无有效目标才回退下一层，不无限穿越战场追击。

### 辅助与治疗

- 辅助选择本方最近的远程攻击单位为跟随对象，安全跟随距离待调试。没有远程时跟随本方近战队伍，不独自冲城。
- 范围内受伤近战优先，再考虑其他受伤友军；同级按缺失生命值最多、再按距离。单位个别限制（不能治疗机械/自己等）仍保留。
- 哥布林医师的“友军”指敌方阵营，不会治疗玩家。所属部族不等于所有成员都有哥布林种族；头领的哥布林光环不自动作用于草原狼。

### 护卫主动迎敌、回援与反刺客

- 2026年11月4日用户修订：有后排时也主动前往攻击敌人，不原地跟随等待。后排包括远程攻击与远程辅助；当前正在攻击后排的敌人、或最近2秒实际造成伤害且仍存活的攻击者，优先于普通目标和全军集火。多个威胁优先最近发生伤害的目标，其次护卫与攻击者距离。攻击者死亡后立即重新寻敌；此为下一逻辑帧响应，不重置攻击冷却或瞬移。
- 无后排威胁时先执行有效集火，再拦截后排附近刺客，最后主动接近最近敌人。保护分摊仍要求距离3以内；护卫出击过远不会无条件替后排承担伤害。英雄独立操作后续接入时保留其命令层级。

- 每名护卫优先保护最近的本方远程攻击单位，无此类单位时再保护远程辅助。保护与反刺客半径初值3逻辑距离，仍需实际调试。
- 一个目标同时最多由一名护卫分摊，优先最近的存活有效护卫；多护卫不叠成60%/90%。一次伤害只分摊一次，不能互相递归分摊。
- 先计算受保护对象自身防御与自身护盾，剩余血量伤害70%由其承受、30%转给护卫。转移伤害不再次减护卫护甲/魔抗，护卫自身护盾可吸收；整次结算保持总量，整数余数归被保护目标。
- 护卫承担分摊后可以死亡；死亡或离开保护范围立即结束分摊。职业保护不会让原目标完全免伤，也不是把30%伤害无条件抹去。
- 对刺客的普通攻击/自身伤害技能基础伤害乘1.3后计算对应防御；转移伤害和其他间接收益不触发该增伤。

### 攻城与武道家

- 对城堡的基础伤害乘1.5后减城堡对应防御，对士兵仍用基础值；不因攻城职业自行获得额外范围伤害。
- 武道家按具体单位卡执行；奶蛙的二次攻击魔法伤害及护盾技能已保存，本次营地版本暂不开放高级英雄招募。
